# 🚀 Quiz-Escolar

**Quiz-Escolar** es una plataforma educativa diseñada para facilitar la labor docente mediante la generación automática de cuestionarios personalizados. A través del uso de inteligencia artificial, los profesores pueden crear evaluaciones completas en segundos, simplemente indicando el tema y curso, o pegando directamente el temario de estudio.

## 🛠 Características Principales

* **Generación Inteligente:** Crea cuestionarios complejos mediante prompts.
* **Diversidad de Preguntas:** Soporta múltiples formatos:
    * Verdadero/Falso.
    * Opción múltiple.
    * Selección en mapa.
    * Problemas matemáticos.
    * Ejercicios de *listening*.
* **Soporte Multimodal:** Integración con generación de imágenes para proporcionar apoyo visual automático.
* **Gamificación:** Sistema de ranking integrado para que los alumnos puedan visualizar su progreso y resultados.
* **Privacidad garantizada:** La aplicación no almacena datos personales, centrándose exclusivamente en ser una herramienta de estudio.

## 🚀 Cómo empezar

Para poner en marcha el proyecto localmente, sigue estos pasos:

1. **Clonar el repositorio:**

```
bash
git clone https://github.com/tu-usuario/quiz-escolar.git
cd quiz-escolar
```

2. **Instalar dependencias:**
```
bash
npm install
```

3. **Configuración:**
   
En el menú de ajustes se configura la escuela y las API's que se desea usar. Las APIs de búsqueda de imágenes se configuran en cada navegador, pero la API de Google quedará en el servidor.

4. **Ejecución:**
```
bash
npm run dev
```

## 📋 Cómo usarlo
1. El profesor inicia sesión y selecciona "Crear nuevo cuestionario".

2. Introduce el tema y curso o pega directamente el texto del temario.

3. La IA genera automáticamente las preguntas y recursos visuales.

4. El profesor revisa y publica el cuestionario.

5. Los alumnos acceden al cuestionario y pueden visualizar su posición en el Ranking una vez finalizado.

## 🔒 Privacidad y Seguridad
- Sin datos personales: La aplicación no recopila información sensible de los usuarios.

- Uso educativo: Diseñada exclusivamente como herramienta de apoyo al estudio.
